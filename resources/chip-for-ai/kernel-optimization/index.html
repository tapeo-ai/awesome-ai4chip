Kernel Optimization

面向 GPU、CPU 和加速器的 kernel 生成、优化、评测与编译工具。

生成、优化与评测

  • AccelOpt（2025/2026） — 利用 slow–fast kernel 对积累优化记忆，在 AWS Trainium 上自主优化 kernel，并提供 NKIBench。 论文
  • AKG kernel Agent（2025） — 用多 agent 自动完成跨 GPU/NPU 的 kernel 生成、迁移和调优，支持多种 kernel DSL。
  • AscSpMM（2026） — 在 Ascend 910B3 上以 Vector-CSR、双槽环形缓冲和自适应分块，将向量引擎的稀疏索引与数据整理和 Cube 引擎的矩阵计算异步流水化。 论文
  • Atrex Kernel Agent（2026） — 围绕 GPU 知识库、profiling 工具与结构化工作流完成 kernel 实现、诊断及迭代优化。
  • AutoProfiler（2026） — 由优化反馈学习确定性的 profiling 决策树，按 kernel 选择硬件计数器，在固定测量预算内为一次 LLM kernel 改写提供信息。 论文
  • AWS Neuron Agentic Development — AWS 官方 NKI agent 工具，覆盖 kernel 编写、编译修复、profiling、性能分析及 API 迁移。
  • BitDecoding-FP4（2026） — 用双残差 query 量化、概率缩放和异常值感知的 key 量化实现原生 FP4 KV 解码；在 NVIDIA B300 上，Qwen3-4B 与 Qwen3-30B-A3B 的峰值服务吞吐达到 BF16 KV 的 2.4–3.0 倍，NVFP4 精度与 BF16 KV 相差不超过 0.5 个点。 论文
  • CompoundingKernel（2026-11-14，补录） — Amazon 用模型外的正确 kernel 与谱系档案指导并行搜索，由独立执行检查验收，并研究测量吞吐和重启恢复对 B200 kernel 搜索扩展性的影响。 项目
  • CUDA Agent（2026） — 把大规模 agentic RL、CUDA 任务数据、专家 skills 与可验证执行环境结合，训练高性能 kernel 生成能力。 论文
  • CUDA-L1（2025/2026） — 以对比强化学习和执行反馈优化 CUDA kernel，讨论性能奖励设计及 reward hacking。 论文
  • ForgeKernel（2026） — 从参考 kernel 的实测硬件行为提取可复用机制，并把通过正确性与性能测试的实现晋升为下一轮参考；在 Hopper 与 Blackwell 的 27 个算子、29 组输入上，25 组不低于专家参考，几何平均增益 10%。 论文
  • KernelAudit（2026-11-11，补录） — 按任务契约分别审计语义正确性、实现完整性和计时完整性，用压力测试、执行轨迹与计时检查定位 kernel 验证器的误接受和误拒绝。
  • KernelBench（2025） — 以 PyTorch 任务评估模型能否生成正确且更快的 GPU kernel，并提供运行与测量工具。
  • KernelMosaic（2026） — 以文本、参考实现和数学描述构建多样 CUDA 任务，生成经执行验证的解答与 agent 轨迹，并用其微调 Qwen3.5-9B 的 kernel 编写和工具反馈修正能力。
  • Kevin-32B（2025） — 通过多轮强化学习训练 CUDA kernel 生成与优化模型，让模型利用执行反馈迭代代码。 论文 模型
  • LARK（2026） — 用 Lean 4 固定 GPU 机器模型与算子语义，由 agent 分段证明生成 kernel 与 PyTorch 参考在精确算术下的功能及内存等价。
  • MaxKernel（2026） — 针对 TPU kernel 提供人机协作、自主优化和图搜索三种多 agent 模式，结合编译、测试和硬件 profiling。 代码
  • PyTorch KernelAgent / KernelFalcon（2025–2026） — 将 kernel 生成、数值验证、硬件 profiling 和瓶颈分析组织为多 agent 闭环，并用共享记忆指导优化。 技术博客
  • RNGD Multi-Agent Kernel Optimization（2026） — 通过文档校验、微基准和编译器合法性规则积累 FuriosaAI RNGD 知识，以 Design Trees 搜索三个 Gemma 解码 kernel，并用重复实机对比验收改动。 测量工具与实验材料
  • Warpline（2026） — 直接在 GPU kernel 二进制中插入探针，把 warp 时间线与硬件 profiling 对齐，使 agent 在源码、IR 或 PTX 修改后无需重编译即可重新取证。
  • ZYFA（2026） — 为 AMD Instinct MI355X 编写 FP8 FlashAttention prefill kernel，用乘加与整数转换代替指数，并重叠 softmax 与矩阵乘；在三份模型注意力输入上达到 AITER 的 1.16–1.76 倍吞吐。 论文

Kernel 与编译工具

  • Arknife（2026） — 用统一约束布局代数描述逻辑张量与硬件轴的映射，通过全局约束求解及目标指令描述生成和修复 x86、Hexagon NPU 与 NVIDIA GPU 的 kernel 布局。
  • Arm KleidiAI — 面向 Arm CPU 的 AI micro-kernel 库，提供按硬件架构优化的矩阵计算与数据打包例程。 主仓库
  • DeepEP — 为 MoE expert parallelism 设计高吞吐与低延迟通信路径，连接模型路由、GPU kernel 和网络传输。
  • oneDNN — 提供深度学习算子与硬件专用 kernel；AMD 与 Intel 宣布计划将 ZenDNN 优化整合到 oneDNN，统一 PyTorch 在 x86 CPU 上的加速路径。 整合公告
  • TauLang（2026） — 面向静态调度加速器的 kernel 语言和编译器，把操作发射周期写成程序参数，并用整数线性规划联合求解张量放置与周期。
  • TileLang — 以 tile 为核心表达 GPU、CPU 和加速器 kernel，简化底层优化与跨硬件后端实现。
  • TLX (Triton Low-Level Extensions)（2026） — 在 Triton 中显式控制 warp-group 执行、异步数据搬运和同步；Meta 分享其在推荐、推理与 LLM 预训练中的生产使用，以及模型、运行时和 kernel 协同优化实践。
  • Triton — 用于编写高性能 GPU kernel 的语言和编译器，是多项 kernel agent 的代码生成目标。
