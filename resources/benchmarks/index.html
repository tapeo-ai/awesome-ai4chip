Benchmark 与评测

RTL、验证、PPA、物理设计、长流程和模拟电路评测。

RTL 生成、理解与仓库上下文

  • ChipVerilog（2026） — 从 OpenCores 设计构建多层次 RTL 生成任务，结合模块等价检查与系统级仿真。 论文
  • NotSoTiny（2025） — 随 Tiny Tapeout 项目更新构建带上下文的模块补全任务，使用形式等价检查降低静态基准局限。 论文 代码
  • RTL-BenchMT（2026） — 用 agent 与形式验证引导识别规格歧义、修订问题并扩展 RTL 生成 benchmark。
  • RTLLM（2023） — 从自然语言规格生成 RTL，配套参考设计、testbench 和综合质量评测。 论文
  • VerilogEval（2023） — 提供 Verilog 代码补全与 spec-to-RTL 评测，用仿真验证生成功能并分析常见失败。 论文
  • Vhdl-RepoBench（2026） — 保留 VHDL 跨文件层次和依赖，评测补全、仓库摘要及规格到模块生成。

验证、断言与调试

  • AssertionBench（2025） — 基于 OpenCores 设计与经过形式核验的参考断言，评估 LLM 从 RTL 生成断言。 论文
  • AssertLLM2（2026） — 围绕规格、完整 RTL 和突变 bug 评估 SVA 的预防错误与发现错误能力。 重跑需要 JasperGold。 论文
  • FIXME（2025） — 覆盖规格理解、参考模型、testbench、SVA 生成与 RTL 修复，含文本和多模态规格。 当前流程含 VCS、VC Static 依赖。 论文
  • FVEval（2024） — 通过 NL2SVA 与 Design2SVA 任务，评估从指令和 RTL 生成断言的形式验证能力。 完整评测需要 Cadence Jasper。 论文
  • HierSVA（2026） — 为层次 RTL 构建参考 SVA，分别评估可证明性、空泛性、规格一致性、突变检测与覆盖率。 重跑需要 VC Formal。 代码 数据
  • ICCAD 2026 — Regression Failure Bucketing（2026） — Synopsys 提供的验证回归失败归类任务，附题目说明、测试材料与阶段评测结果。

PPA 优化与 HLS

  • Bench4HLS（2026） — 评测 LLM 生成 HLS C++ 的仿真正确性、综合可行性与 PPA，覆盖从 kernel 到加速器的任务。 当前工具链为 Vitis HLS/Vivado。 论文
  • CktEvo（2026） — 以多文件 IP 仓库为对象，在保持功能正确的前提下优化 RTL 的 PPA。 论文
  • MetRex（2025） — 将 RTL 与综合后的面积、时延、静态功耗及自然语言推理对应，评估指标估算能力。 论文 数据
  • Pluto（2025） — 用面向面积、时延和功耗分别优化的参考实现评估 LLM 生成硬件的效率。 论文 数据
  • RTL-OPT（2026） — 提供次优 RTL 与人工优化参考对，评估功能保持前提下的 PPA 改进。 论文

网表与物理设计

  • FloorSet Challenge（2026） — Intel 提供带设计约束的合成 SoC floorplanning 数据、优化器模板与评测脚本，用于比较数据驱动的布局规划方法。
  • ICCAD 2025 — Incremental Placement Optimization（2025） — NVIDIA 提供门尺寸调整、缓冲插入和单元移动的联合任务，评测详细布局后的增量优化。 论文页
  • ICCAD 2026 — LLM-Assisted Netlist Exploration and Transformation（2026） — Cadence 提供的 LLM 辅助网表探索与变换任务，附题目说明和测试材料。

综合设计任务与长流程评测

  • Build-A-Chip-Bench（2026） — 评测 agent 从工作负载规格完成 GDS 的能力，检查功能、时序、布线和 DRC，再按 PPA 评分。 实时榜单待上线。
  • ChipBench（2026） — 覆盖层次化 Verilog 生成、RTL 调试及 Python/SystemC/CXXRTL 参考模型生成。 论文
  • CLOSER-Bench（2026） — 以 10 项试验任务比较 spec-to-RTL、RTL-to-GDS 和 spec-to-GDS 流程，研究预算分配与跨阶段修复。
  • CVDP（2025） — 由工程师编写芯片设计与验证任务，涵盖单模块和仓库级工作，并提供 Docker 运行环境。 部分任务使用商业 EDA 工具。 论文 数据

模拟、混合信号与多模态

  • AMSbench（2025） — 覆盖模拟/混合信号原理图感知、分析和设计的多模态评测。 数据
  • AnalogGym（2024） — 提供多类模拟拓扑、规格和仿真测试，支持比较自动尺寸优化方法。
  • CircuitSense（2026） — 评估从电路图感知到符号方程推导及设计推理，并提供合成生成流水线。 数据
  • Long-Horizon Analog Design Bench（2026） — 以 SKY130/ngspice 下的长时设计任务评估模拟/混合信号 agent，验收范围是原理图级电气指标。
  • NetlistBench（2026） — 以确定性结构 oracle 检验 SPICE 网表识别、编辑、层次操作及等价判断。
