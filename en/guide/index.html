Guide

Reading and practical paths for model researchers, EDA engineers, and computer architects.

If chip design is new to you, start with EDA 101: a flow diagram connects RTL, verification, synthesis, place and route, and signoff to the software used at each stage.

AI Model

For readers familiar with LLMs who want to research RTL generation, domain post-training, or evaluation. Read the survey, establish an evaluation setup, then study a training implementation.

  1. LLMs for EDA: A Survey — Section 3 covers EDA tasks, section 4 model adaptation, and section 5.1 data and evaluation. Use it to identify the data and checks needed for a particular task: generating RTL, generating assertions, or answering questions about design documents.
  2. VerilogEval — Follow the README’s spec-to-rtl flow from a specification through generated Verilog to simulation results. It makes a basic evaluation distinction concrete: compiling successfully and implementing the specification are different requirements.
  3. CodeV-R1 — Study a concrete Verilog post-training project. Read the evaluation instructions in test/, training configurations in sft/, then the RL pipeline and testbench reward in verl/. Compare these with the released data to see how reasoning distillation and simulation feedback enter training.

If reading simple RTL is still difficult, begin with combinational and sequential logic exercises in HDLBits, then cocotb First Steps to connect Python testbenches with clocks, reset, assertions, and waveforms. Continue through Data, Benchmark, or Training for your research question.

AI EDA

For readers with RTL / EDA experience who want to build design agents or automated optimization flows.

  1. The Dawn of Agentic EDA — Read section 2 on agent architectures, then choose section 3 on RTL / Verification or section 4 on Physical Design. Follow how tool calls, task decomposition, and feedback are organized, and where deterministic EDA checks remain necessary.
  2. OpenROAD Flow Scripts Tutorial — Follow the Ibex / SKY130 example through RTL to GDS. Start with Running the Automated RTL-to-GDS Flow, then use the directory guide to inspect synthesis, floorplan, CTS, and routing results. The tutorial connects commands, artifacts, the GUI, and timing reports.
  3. OpenROAD — Running Claude Code in Docker — Connect a coding agent to a container with EDA tools and see how it accesses a project, builds, and runs tests. Read this after completing an ORFS run to bring an existing design flow into an agent workflow.

For synthesis optimization, continue with Yosys Synthesis Starter to follow a FIFO from RTL to a netlist. For verification, use SymbiYosys Getting Started to learn assertions, bounded checks, proofs, and counterexamples. Find projects in AI EDA and EDA Optimization.

Analog / Mixed-Signal

Readers with circuit fundamentals who want an analog design and optimization environment can follow JKU Analog Circuit Design: chapters 1 and 2 introduce Xschem, ngspice, and an open PDK; chapter 3 covers gm/ID sizing; chapter 8 develops OTA simulation, PVT, and Monte Carlo analysis. The course includes circuit files and Python notebooks.

To connect simulation to parameter search or agents, continue with the looping, parameter modification, and data export sections of the ngspice Control Language Tutorial.

Chip for AI

For readers with machine learning or computer architecture foundations who want to study model–accelerator co-design.

  1. MIT 6.5940 — TinyML and Efficient AI Computing — Start with Introduction, then Quantization and Neural Architecture Search. Lectures, videos, and labs connect accuracy, computation, memory requirements, and deployment cost, providing a foundation for hardware-aware ML.
  2. Timeloop / Accelergy v4 and its exercises — Read Problem, Architecture, and Constraints to distinguish workloads, hardware, and mapping constraints. Then run the exercises and compare data movement, cycles, and energy using Stats / Mapping outputs. This introduces DSE without first implementing an RTL accelerator.

To study an accelerator’s hardware and software together, continue with Gemmini Quick Start: start with matrix multiplication in the simulator, then read Architecture for the systolic array, scratchpad, accumulator, and dataflow. Explore Hardware-aware ML, DSE, DSA, or Kernel Optimization for further work.
